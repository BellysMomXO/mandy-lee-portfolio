# Madd Hatter

Business website and portfolio experience

## Problem

Businesses need to understand the practical value of systems and automation before they can choose a solution.

## What I built

A responsive marketing website explains connected customer experiences, presents services and pricing, and guides visitors toward an inquiry or digital readiness assessment.

## Capabilities

- Responsive static HTML and CSS
- Accessible expandable project details
- Structured metadata and schema
- Contact form integration
- Image lightbox and progressive reveals
- Digital readiness assessment with optional review submission

## Connected workflow

```text
Discovery → examples → services → readiness assessment or inquiry
```

## Implementation

HTML, CSS, JavaScript, Cloudflare static assets, Tally, Web3Forms.

## Status and boundaries

The main website is public. The new Our Work page is currently a local draft and must be deployed before it becomes shareable.

The public link opens the existing deployed homepage, not the unpublished portfolio draft.
